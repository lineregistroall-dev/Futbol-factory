TACTICPAD WEB — VERSION RESPONSIVE

Esta versión reorganiza la interfaz para que la cancha sea el área principal y los menús aparezcan debajo de ella.

MEJORAS
- Diseño responsive para teléfono, tablet y computadora.
- Menús inferiores: Herramientas, Jugadores, Animar, Equipo, Acciones, Proyecto y Selección.
- Nuevas herramientas: Arco y Valla de salto.
- Arco y valla disponibles en 2D y 3D.
- Botón de instalación como aplicación cuando el navegador/PWA lo permite.
- Exportación de vídeo 2D y 3D desde el primer fotograma hasta el último fotograma, sin repetir la secuencia.
- El vídeo termina exactamente en el último fotograma creado.
- Descarga de proyectos JSON y exportación PNG.

INSTALACIÓN
1. Sube todos los archivos de esta carpeta al repositorio de GitHub.
2. Mantén GitHub Pages apuntando a la rama principal y a la carpeta raíz.
3. Abre la página en Chrome.
4. En teléfono, usa "Instalar" o "Añadir a pantalla de inicio" cuando aparezca la opción.
